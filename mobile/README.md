# MOVA mobile (starter Expo)

Visual starter for the rider and driver screens. **Nothing is connected**: no accounts, GPS, dispatch, SMS or payments.

```bash
cd mobile
npm install
npx expo start
```

Then open it in Expo Go (Android/iOS) or press `w` for the web preview (requires `npx expo install react-dom react-native-web @expo/metro-runtime`).

Next steps toward a real app are listed in the handoff (phase D): backend/API, secure auth, real-time dispatch, routing, push/SMS, marketplace payments.
